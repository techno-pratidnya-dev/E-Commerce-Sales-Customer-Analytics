# E-Commerce Sales & Customer Analytics

## Project Overview
This project focuses on analyzing e-commerce sales and customer data using Python, SQL, Excel, and Power BI to identify sales trends, customer behavior, and business insights.

## Tools & Technologies
- **Python:** Data cleaning and analysis
- **SQL:** Data querying and analysis
- **Microsoft Excel:** Data cleaning and reporting
- **Power BI:** Interactive dashboards and data visualization

## Project Objectives
- Analyze overall sales and revenue performance.
- Identify top-performing product categories.
- Understand customer purchasing behavior.
- Explore sales trends and patterns.
- Build interactive dashboards to support data-driven decisions.

## Repository Structure
- `data/` – Dataset files
- `Python/` – Python analysis files
- `sql/` – SQL queries
- `excel/` – Excel analysis files
- `PowerBI/` – Power BI dashboard files

## Key Insights
The project explores sales performance, product categories, customer trends, and business metrics through data analysis and visualization.

## How to Explore
1. Open the relevant project folder.
2. Review the data and analysis files.
3. Explore SQL queries and Excel analysis.
4. Open the Power BI files using Power BI Desktop.
